NeuroSDR — Download, supported radios, and RTL-SDR / Zadig install

This post is for people who want to run NeuroSDR, not compile it. Author: KD8CEC.

1. Download the release (not the source zip)

  1. Open github.com/phdlee/NeuroSDR/releases.
  2. Under Assets, download the newest Windows x64 zip (example name: NeuroSDR-v0.2-win-x64.zip).
  3. Extract the entire archive to a writable folder (for example C:\NeuroSDR).
  4. Run NeuroSDR.exe.
Do not use the green Code → Download ZIP button on the repository home page for day-to-day use. That is the source tree for developers.

English install text also lives in the repo as INSTALL.md (plus KO/JA/ZH copies).

2. What is already inside the zip

  • NeuroSDR.exe and the runtime files needed for that package
  • Bundled native helpers for common USB SDRs (RTL-SDR, HackRF, Airspy, …) under paths such as native\
  • Built-in AF / IQ plugins that ship with the app

You usually do not hunt extra DLLs for RTL-SDR / HackRF / Airspy beyond the release folder.

4. RTL-SDR and Zadig (read this carefully)

On Windows, an RTL-SDR stick often arrives bound to a TV or storage-style driver. NeuroSDR (and librtlsdr) expect a WinUSB (or compatible libusb) binding on the bulk interface.

Use the latest Zadig. Older Zadig builds frequently fail to install WinUSB on current Windows, and then the stick never appears as a usable SOURCE.

  1. Download the newest Zadig from the official site: https://zadig.akeo.ie/ (or the newest asset on the libwdi releases page). As of writing, that is Zadig 2.9.
  2. Plug in the RTL-SDR.
  3. Run Zadig as Administrator if Windows asks.
  4. Enable Options → List All Devices.
  5. Select the SDR bulk interface. For many RTL-SDR sticks this looks like Bulk-In, Interface (Interface 0) / Realtek. Avoid Storage or HID-only entries.
  6. On the right, choose WinUSB.
  7. Click Install Driver or Replace Driver and wait for success.
  8. Start NeuroSDR → choose the RTL-SDR SOURCE → RX START.
If NeuroSDR still shows no RTL device: try another USB port / cable, close other SDR apps that hold the stick, and confirm you replaced the driver on Interface 0 — not a random composite child.

5. SDRplay

NeuroSDR loads the vendor API from the normal SDRplay install path. The release zip does not replace that installer.

  1. Install SDRplay API 3.x from the SDRplay website.
  2. Reboot if the installer asks.
  3. Connect the RSP, pick the SDRplay SOURCE, press RX START.

6. First run checklist

  1. Run NeuroSDR.exe.
  2. Pick a SOURCE (hardware or Kiwi/WebSDR/OpenWebRX).
  3. For remote sources, use Find or paste a site URL, then save favorites if you like.
  4. Press RX START.
  5. Open SET for audio devices, AF plugins, RF performance, and optional web remote.
Find SDR site — search the Kiwi / WebSDR / OpenWebRX directory.
SET → Plugin — choose spectrum / waterfall render plugins.

Settings live under %LocalAppData%\NeuroSDR\ on your PC.

Optional: SETUP → General → VOICE GUIDANCE uses offline eSpeak NG if installed. Optional: ENABLE WEB REMOTE for browser control (LAN bind + token available on the same page).
