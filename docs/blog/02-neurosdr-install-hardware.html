NeuroSDR — Download and install for real SDR hardware

This guide is for people who download a release and run NeuroSDR on Windows with a dongle or RSP. Author: KD8CEC.

Repo install text (English + KO/JA/ZH): INSTALL.md.

1. Get the software

  1. Open GitHub Releases (not the green Code zip on the repo home page).
  2. Download the newest Windows x64 asset (example: NeuroSDR-v0.2-win-x64.zip).
  3. Extract everything to a writable folder (e.g. C:\NeuroSDR).
  4. Run NeuroSDR.exe.
Old Zadig builds break RTL-SDR on modern Windows. Always use the latest Zadig when you need WinUSB.

2. What the zip already contains

  • NeuroSDR.exe and supporting runtime files for that package
  • Bundled native helpers for common USB SDRs (RTL-SDR, HackRF, Airspy, …) under paths such as native\
  • Built-in AF / IQ plugins

You normally do not download extra librtlsdr DLLs for those sticks beyond the release folder.

3.1 SDRplay

  1. Install SDRplay API 3.x; reboot if asked.
  2. Connect the RSP.
  3. Start NeuroSDR → select the SDRplay SOURCE → RX START.
  4. Use SET → RF / Performance for sample rate, hardware AGC, and related RSP options.

3.2 RTL-SDR — Zadig (step by step)

Windows often binds the stick to a TV/storage-style driver. NeuroSDR needs WinUSB (libusb) on the bulk data interface.

  1. Download the newest Zadig from https://zadig.akeo.ie/ (or newest libwdi release). Prefer Zadig 2.9+.
  2. Plug in the RTL-SDR.
  3. Run Zadig (Administrator if Windows asks).
  4. Options → List All Devices.
  5. Select Bulk-In, Interface (Interface 0) / Realtek-style entry — not Storage/HID-only children.
  6. Target driver: WinUSB.
  7. Install Driver or Replace Driver; wait for success.
  8. NeuroSDR → SOURCE = RTL-SDR → RX START.
If the stick still never appears: another USB port/cable, close SDR# / HDSDR / dump1090 holding the device, confirm you replaced Interface 0.

3.3 HackRF / Airspy

Same Zadig idea when Windows has not already bound WinUSB. Then pick HackRF One or Airspy / Airspy HF+ in SOURCE.

3.4 SoapySDR devices

Install PothosSDR (or another Soapy install). NeuroSDR looks for SoapySDR.dll in common locations such as %ProgramFiles%\PothosSDR\bin\.

4. Secondary path — no hardware (Virtual WebSDR / Kiwi / OpenWebRX)

If you cannot plug a dongle in yet, SOURCE entries like Virtual KiwiSDR / WebSDR / OpenWebRX let you practice tuning, captions, and AF plugins over the Internet. Use Find to search the directory, or paste a site URL.

Find SDR site — optional remote directory (secondary to local hardware).

5. First run on hardware

  1. Install vendor API / Zadig as above.
  2. Run NeuroSDR.exe.
  3. Select your hardware SOURCE.
  4. Press RX START.
  5. Open SET → Audio and pick a real waveOut device for OUT1.
  6. Tune with click / wheel on the waterfall; set mode and BW.
SET — Plugin page (spectrum / waterfall renderers). Other tabs: Audio, AF Plugins, IQ Plugins, General, RF / Performance.

Settings folder: %LocalAppData%\NeuroSDR\.

Optional later: SET → General → VOICE GUIDANCE (eSpeak NG), ENABLE WEB REMOTE.
