1. Sub VFOs — listen here, decode there

A Sub VFO is an independent virtual receiver inside the instantaneous RF window of your source. On a wide SDRplay capture you can park MAIN on a shortwave broadcast while SUB1/SUB2/SUB3 decode FT8 on 14.074, 7.074, 7.040, …

  1. Add Sub VFOs from the UI (+ ADD / context menu on the spectrum).
  2. Set each Sub VFO frequency, mode, bandwidth, and output channel (or DEC-only).
  3. In SET → AF Plugins, point FT8 instances at those Sub VFO IDs.
  4. Watch for OUT OF RANGE when a Sub VFO leaves the current capture / viewport.

2. SCENE system (including Satellite)

Scenes store the working set: source, plugins, Sub VFOs, waterfall view, and more. The Satellite scene adds observer location, pass priority, and Doppler-aware retuning — including experiments against VHF/UHF-capable WebSDR/Kiwi nodes.

3. Digital voice (DMR / D-STAR / C4FM)

NeuroSDR embeds a DSD-FME based path so digital voice can decode inside the app. Use the digital mode panel for feed AGC / volume / output channel. On the optional web remote, only decoded voice should play — not raw discriminator noise.

4. Smart Record

5. Web remote (browser / phone)

In SET → General, enable ENABLE WEB REMOTE. Optionally bind all interfaces for LAN phones and set an access token. The status bar shows a URL such as http://127.0.0.1:8765/.

The web UI mirrors RX start/stop, frequency, mode, bandwidth, scenes, sites, meters, spectrum/waterfall (including Kiwi rows), AF plugins feed, and decoded digital voice audio.

Video status: A dedicated web-remote YouTube episode is planned but not published yet. Until then, use this section + the in-app SETUP labels. I will link the video here when it goes up on the channel.

6. Config export / import

From the title-bar chrome menu → Config: Export / Import / Reset settings. Useful when moving a SCENE-heavy setup between PCs — still scrub personal GPS / API keys before sharing files publicly.
