This is the everyday operating guide. Author: KD8CEC. Pair it with the videos when a gesture is faster to see than to read.

1. RX CONTROL (left column)

  • Frequency digits — Click a digit, then use the mouse wheel to nudge that decade. You can also type a frequency into the digital entry and commit with Enter (same spirit as the desktop VFO).
  • SOURCE — Local dongle, rtl_tcp, KiwiSDR, WebSDR, OpenWebRX, IQ playback, etc.
  • SET — Opens NeuroSDR SETUP (Plugin / Audio / AF Plugins / IQ Plugins / General / RF Performance).
  • RX START / RX STOP — Starts or stops the receiver pipeline.
  • RF GAIN — Hardware / source gain where applicable.
  • RF / AF meters — Signal and audio level while receiving.
  • SCENE — Named layout: SAVE / NEW / DEL. Scenes remember a surprising amount of state (plugins, Sub VFOs, remote site, pop-outs).
  • Mode chips — AM, SAM, DMR, DSTAR, C4FM, FDV, NFM, WFM, USB, LSB, CW, …
  • Band chips — Quick jumps (MW, SW, ham bands, FM, AIR, …).
  • BW presets — Filter bandwidth shortcuts around the current mode.
  • OUT 1 / OUT 2 — Volume and squelch. Dual output is intentional for piping a second stream to other software.

2. Spectrum / waterfall gestures

  • Click — Tune the VFO to that frequency.
  • Drag on the signal area — Retune while dragging.
  • Wheel — Zoom the view span.
  • Ctrl / Shift + wheel — Nudge the VFO (see on-screen hint).
  • Drag background / right-drag — Move or pan the view (especially important on Kiwi/WebSDR where the server waterfall window is independent of the audio VFO).
Video: Spectrum / waterfall levels on Kiwi (00:40)

3. Remote sites (Kiwi / WebSDR / OpenWebRX)

  1. Set SOURCE to KiwiSDR, WebSDR, or OpenWebRX.
  2. Press Find to search the directory, or paste a URL into the site box.
  3. Use Add (star) to keep favorites.
  4. Press RX START.
Find SDR site — filter by protocol, HF/VHF/UHF, search text.

Classic WebSDR sites may not support every desktop feature (for example some AFC behaviors). Kiwi usually feels closest to a local radio for viewport control.

4. SET — the pages you will actually use

SET → Plugin — spectrum / waterfall plugin selection.
  • Plugin — RF spectrum & waterfall renderers.
  • Audio — Enable OUT1/OUT2 and pick waveOut devices.
  • AF Plugins — Add rows: FT8, CW, NeuroCaption, SSTV, WEFAX, … each with a VFO target.
  • IQ Plugins — Pre-demod IQ consumers (for example ADS-B style paths when enabled).
  • General — CW default side, tuner offset, WEB REMOTE, rtl_tcp endpoint, voice guidance.
  • RF / Performance — Sample-rate / hardware options (SDRplay AGC, HackRF amp, display rate, diagnostics).

5. Recording buttons (sidebar)

  • Open IQ WAV / Start IQ Recording — Capture or play IQ.
  • Record — AF recording.
  • Smart Record — Time-of-day schedules (next advanced post).
  • Memory / Scan — Memory bank and scanning tools.
Smart Record — schedule audio jobs by local time and day.

6. Suggested first hour

  1. Remote path: SOURCE = KiwiSDR → Find a quiet HF site → RX START → USB/LSB on a broadcast or ham band.
  2. Local path: Zadig + RTL-SDR or SDRplay API → SOURCE = your dongle → RX START.
  3. Open SET → Audio and confirm OUT1.
  4. Add FT8 or NeuroCaption from SET → AF Plugins when you are ready for the next posts.
