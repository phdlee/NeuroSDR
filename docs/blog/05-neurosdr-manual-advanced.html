NeuroSDR user manual (3) — Sub VFO, satellite, digital voice, Smart Record, web remote

Advanced workflows. The Sub VFO / multi-FT8 story assumes hardware with enough instantaneous bandwidth. Author: KD8CEC.

1. Sub VFOs on wide hardware (founding goal)

A Sub VFO is an independent virtual receiver inside the RF capture window. On an RSP (or other wide source), you can:

  • Listen to shortwave or CW on MAIN
  • Run FT8 plugins on SUB1 / SUB2 / SUB3 at 14.074, 7.074, 7.040 MHz, …
  • See decoded callsigns on the main waterfall when MAIN WF overlay is enabled

If a Sub VFO leaves the capture, the UI shows OUT OF RANGE — raise sample rate / recenter, or accept that the decoder pauses.

2. SCENE and Satellite mode

Scenes store source, plugins, Sub VFOs, and view. The Satellite scene adds observer position, pass priority, and Doppler-aware retuning. You can also experiment against VHF/UHF-capable remote nodes, but GPS home and Doppler math are aimed at real tracking work.

Enter your observer coordinates in the Satellite UI. Do not publish personal home GPS in shared settings files.

3. Digital voice (DMR / D-STAR / C4FM)

NeuroSDR embeds a DSD-FME-based path. Select the digital mode, use the digital panel for feed AGC / PCM volume / output channel. Decoded voice owns the speaker path — you should hear voice, not raw discriminator hash.

5. Web remote (optional)

SET → General → ENABLE WEB REMOTE. Optional LAN bind + access token. Status bar shows a URL (often http://127.0.0.1:8765/). Browser UI can start/stop RX, tune, change mode, show spectrum/meters, and play decoded digital voice.

A dedicated YouTube episode for web remote is not up yet. I will link it here when published. Until then, use SET → General labels and this section.

6. Config export

Title-bar chrome menu → Config → Export / Import / Reset. Scrub API keys and home GPS before sharing exports.
