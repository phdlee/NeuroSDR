NeuroSDR — An AI-built SDR receiver for real listening, not demos

Hello. This is KD8CEC.

NeuroSDR is a Windows software-defined radio (SDR) receiver I have been developing and testing with AI agents (primarily Grok). The goal was not a toy UI that only looks like an SDR. The goal was a daily driver: tune local hardware or public Kiwi/WebSDR sites, decode the modes amateurs actually use, and add a few capabilities that conventional desktop SDR packages still treat as exotic.

Public release packages and source are on GitHub: NeuroSDR Releases.

NeuroSDR 0.2 main window — RX control, KiwiSDR source, FT8 AF plugin, spectrum/waterfall.

1. What is different

Most SDR software is excellent at RF plumbing: FFT, demodulators, waterfall colors. NeuroSDR aims to keep that baseline and fold in AI-assisted listening plus a plugin host that stays useful while you are still watching the waterfall.

  • AI audio captions (NeuroCaption) — Speech-to-text on demodulated audio, with optional live translation. Engines include local ONNX/Sherpa Whisper, Groq cloud Whisper, and a self-hosted Whisper server path.
  • AF / IQ plugin architecture — FT8/FT4, CEC CW, SSTV, RTTY, weather fax, Kiwi-oriented helpers, ADS-B / experimental IQ paths, digital voice bridges, and more can run as scene-owned instances.
  • Sub VFOs — Independent virtual receivers inside the capture window so you can listen to shortwave on MAIN while FT8 decoders keep working on other dial frequencies.
  • SCENE system — Layout, plugins, Sub VFOs, and remote site choices travel together (including a Satellite scene with Doppler-aware tracking).
  • Dual audio outs + RNNoise / CW active filters — Route OUT2 to VB-CABLE for WSJT-X/FLDIGI while RNNoise cleans voice on OUT1.
  • Remote sources without hardware — KiwiSDR, classic WebSDR, and OpenWebRX as first-class SOURCE types.
  • Optional web remote — Browser / phone control with spectrum, meters, and decoded digital voice when enabled in SETUP.

2. AI captions are not a gimmick panel

NeuroCaption is an AF plugin. You attach it to MAIN (or a Sub VFO), open SETUP inside the caption chrome, pick an engine, and decide whether captions ride the AF waterfall ticker. Translation can target English or other languages via MyMemory when configured.

That means you can park a KiwiSDR on a foreign shortwave broadcast, keep listening, and read (or translate) speech without a separate transcription workflow. Episode #2 shows captions on remote Kiwi audio end-to-end.

3. Classical SDR features are still there

NeuroSDR is not “AI only.” The everyday radio surface is intentional:

  • Modes: AM, SAM, NFM, WFM, USB, LSB, CW, RAW, FreeDV, plus digital voice modes (DMR / D-STAR / C4FM) through the embedded DSD-FME path.
  • Click / drag / wheel tuning, AFC on analog modes, bandwidth presets, dual OUT volumes and squelch.
  • Memory / scan, IQ and AF recording, Smart Record schedules, EiBi shortwave schedule helpers, on-air markers.
  • Hardware sources: SDRplay, RTL-SDR, HackRF, Airspy, optional Soapy devices, plus rtl_tcp.
